# 📊 SLA Monitor — CLI Tracker for Incident & SLA Management

**SLA Monitor** — это консольное Python-приложение (CLI) для учета задач, управления их жизненным циклом и автоматического контроля выполнения дедлайнов (SLA). 

Проект разработан в рамках практического применения базового стека Python, стандартных библиотек и работы с файловой системой и JSON.

---

## 🚀 Основные возможности

* ➕ **Создание тикетов:** Регистрация задач с указанием названия, описания и допустимого времени выполнения (SLA в часах).
* 📋 **Просмотр и мониторинг:** Отображение списка всех тикетов с отслеживанием прошедшего времени и текущих статусов.
* 🔎 **Поиск и фильтрация:** Поиск задач по `ID`, `NAME` или `STATUS` (`OPEN`, `IN_PROGRESS`, `CLOSED`, `EXPIRED`).
* ⚡ **Автоматический контроль SLA:** Динамический расчет дедлайнов и автоматический перевод просроченных тикетов в статус `EXPIRED`.
* ✏️ **Управление статусами и удаление:** Изменение этапов выполнения тасков и поддержка чистки базы данных.
* 💾 **Локальное хранение:** Автономное сохранение всех данных в формате JSON с обработкой ошибок и валидацией ввода.

---

## 🛠 Технологии и архитектура

### Использованный стек:
* **Python 3.10+** — основной язык разработки.
* **Стандартная библиотека Python (`stdlib`):**
  * `json` — сериализация и десериализация базы данных тикетов.
  * `datetime` & `timedelta` — парсинг времени, подсчет дедлайнов и проверка SLA.
  * `pathlib.Path` — кроссплатформенная и безопасная работа с путями файловой системы.

### Структура проекта:
- SLA monitor/
- ├── main.py          # Точка входа в приложение, главный цикл CLI-меню
- ├── handlers.py      # Бизнес-логика: создание, поиск, авто-проверка SLA, CRUD-операции
- ├── utils.py         # Вспомогательные функции отрисовки CLI и меню
- ├── database.json    # Локальное JSON-хранилище данных
- ├── .gitignore       # Исключения Git (кэш, venv, тестовые скрипты)
- └── LICENSE          # Лицензия проекта (MIT)

## 📦 Установка и запуск

#### Клонируйте репозиторий:
    git clone https://github.com/OkeyLooft/sla-monitor.git
    cd sla-monitor

#### Запустите приложение:
(Дополнительные зависимости не требуются, используется встроенный интерпретатор Python)
python main.py

## 💡 Пример использования

1. Create ticket
2. Show ticket
3. Search ticket
4. Change status
5. Delete ticket
6. Check SLA
7. Exit

--------------------------------------------------
- id: 11
- name: Восстановление доступности VPN
- description: Настроить маршрутизацию для удаленных сотрудников
